# DTB bank

Github workflow that compiles all Rockchip and Allwinner DTBs from various kernel revisions
and publishes them in tags/releases in this Github repo.

Intended use case is for UEFI boot setups like with edk2-rk3588 where the OS image won't have a dtb. You can find
ready to go DTBs here, or have a script that downloads them automatically.
